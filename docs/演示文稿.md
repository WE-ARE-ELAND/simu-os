我们小组完整实现了课程设计任务书所要求的内容，接下来演示我们小组的作品：

首先我们在终端使用 makefile 对源文件进行编译、链接和运行：
```bash
make -f makefile
./build/launch
```

程序运行后登录管理员账号（`admin` / `admin`），进入模拟操作系统。界面显示可输入的命令：

```
mkdir rmdir cd ls rm touch tree readfile readDisk write rename refresh quit
disk(查看磁盘信息)
```

这些命令大多模仿 Linux 命令。

我们可以先创建几个层级目录，试一下 `tree` 功能：
```
mkdir demo          # 创建目录 demo
cd demo
mkdir sub
cd ..
tree                # 显示目录树
```

接下来我们可以删除一个空目录：
```
cd demo
rmdir sub           # 删除空子目录
cd ..
```

然后我们可以创建文件，创建文件会调用数据生成线程，所以主线程不会阻塞，可以继续执行其他命令：
```
touch hello.txt     # 创建文件，输入内容
ls                  # 此时可能看不到文件（后台线程尚未完成）
```
过一会待显示"目录项创建成功"后，再输入 `ls` 即可看到目录中存在该文件。

接下来我们可以 `readfile` 读入该文件，读入后会显示该文件在内存占用哪些内存块（`*` 表示已被占用），并显示该进程的页表和该文件所在磁盘块的位置与内容。

接下来我们可以尝试删除该文件，由于文件已经读入内存，删除会失败（文件保护）。

接下来我们再创建并打开两个文件，模拟全局置换 LRU 算法。可以看到最后一次打开文件时，已有内存块被置换出去——被置换的是最近最久未使用的内存块。

最后可以输入 `disk` 查看空闲盘块，这些盘块通过成组链接法组织，显示的是当前超级块信息。

演示完毕，输入 `quit` 退出，程序会把磁盘镜像保存到 `disk.txt`。
